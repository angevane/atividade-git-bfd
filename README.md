# Atividade Git e Python

## O que é controle de versão?
Controle de versão é uma forma de registrar alterações em arquivos ao longo do tempo, permitindo voltar a versões anteriores e acompanhar o histórico do projeto.

## Importância do controle de versão
Ele é essencial para organização, trabalho em equipe, segurança do código e controle de mudanças.
